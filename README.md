# AI-Based Text Analyzer and Document Classifier

## Internship Organization
GeoNixa

## Domain
Artificial Intelligence and Machine Learning

## Project Description

This project is an AI-based Text Analyzer and Document Classifier developed using Python and Machine Learning.

The system analyzes text files, extracts useful information, identifies important words using TF-IDF, and classifies text into categories such as Technology and Sports.

## Technologies Used

- Python
- Natural Language Processing (NLP)
- TF-IDF
- Scikit-learn
- Logistic Regression
- Git and GitHub

## Features

- Text file analysis
- Word counting
- Word frequency analysis
- TF-IDF important word extraction
- Text classification
- Prediction confidence
- File statistics
- Category summary
- Model accuracy testing

## Machine Learning Workflow

1. Load training text data
2. Assign categories to the text
3. Convert text into TF-IDF features
4. Train Logistic Regression model
5. Test the model
6. Predict text categories
7. Calculate model accuracy
